# Contributor and agent guide

This page is for humans and coding agents making changes to Valen.

## Start with the current implementation

Read the relevant bootstrap and self-hosted files before editing. Valen intentionally evolves in small, testable steps; do not infer syntax from another language when the fixtures and compiler can answer the question.

## Preserve the bootstrap boundary

The JavaScript compiler only needs enough capability to compile the native Valen compiler. A feature may be implemented only in the native language/library when generation 0 does not need to parse or lower it.

Before using a new language construct inside `src/`, confirm the JavaScript bootstrap supports it. Otherwise generation 0 will stop building generation 1.

## Keep implementations aligned where required

Changes to IR or behavior used by the self-hosted compiler usually require checking both:

- `bootstrap/*.js`
- the corresponding `src/lib*.ar`

Runtime/backend changes used by native conformance programs must work when assembly is generated by both generations.

## Test in layers

Use the narrowest relevant test first, then run:

```sh
node bootstrap/test/pipeline.test.js
node bootstrap/test/generation1.test.js
```

After JavaScript changes, run `node --check` on the modified file. Native behavior should be executed, not only inspected in generated assembly.

## Documentation policy

- Describe implemented behavior in the present tense.
- Mark designed, partial, or unavailable features as **WIP**.
- Prefer a small compiling example over pseudocode.
- Update the relevant focused reference when semantics change.
- Keep active ticket status in the [issue tracker](https://gitea.hallrd.click/dthompson/valen/issues); checklists are roadmap snapshots.

## Change and ticket discipline

Keep commits focused on one ticket or one tightly related cluster. Verify the working tree before committing, mention the relevant issue number, record validation in the issue, and close it only after the implementation and documentation are complete.
